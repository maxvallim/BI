Parte 1 - Conhecendo a Base de Dados

A planilha contém os seguintes campos:

  • Data
  • Cliente
  • Cidade
  • Produto
  • Categoria
  • Quantidade
  • Valor Unitário
Pergunta inicial:

Podemos confiar nesses dados exatamente como estão?

Ao analisar a base, observamos problemas de qualidade de dados:

  • Datas em formatos diferentes
  • Clientes escritos de formas diferentes
  • Cidades com e sem acentuação
  • Categorias inconsistentes
  • Registros duplicados

Parte 2 - ELT com Power Query

Passo 1 - Carregar os dados

Selecione a tabela e utilize:

Dados → De Tabela/Intervalo

O Excel abrirá o Editor do Power Query.

Passo 2 - Corrigir as Datas

Converter toda a coluna Data para o tipo:

Tipo de Dados → Data

Passo 3 - Padronizar Clientes

Exemplos encontrados:

Ana Santos
ANA SANTOS
Ana Santos

Padronizar utilizando:

Transformar → Formatar → Primeira Letra de Cada Palavra Maiúscula

Passo 4 - Padronizar Cidades

Exemplos:

São Paulo
SAO PAULO
Ribeirão Preto
Ribeirao Preto

Padronizar nomes e corrigir diferenças de grafia.

Passo 5 - Padronizar Categoria

Exemplos:

Informática
informatica
Informatica

Utilizar Substituir Valores para manter apenas:

Informática

Passo 6 - Remover Duplicidades

Remover Linhas → Remover Duplicadas

Passo 7 - Criar Coluna de Faturamento

Criar uma nova coluna:

Faturamento = Quantidade × Valor Unitário

Fórmula:

=[Quantidade] * [Valor Unitario]

Passo 8 - Fechar e Carregar

Página Inicial → Fechar e Carregar

Agora os dados estão prontos para análise.

Parte 3 - Criando a Tabela Dinâmica

Selecione a tabela tratada.

Inserir → Tabela Dinâmica

Crie a tabela dinâmica em uma nova planilha.

Parte 4 - Construção dos KPIs

KPI 1 - Faturamento Total

Valores: Soma de Faturamento

KPI 2 - Faturamento por Cidade

KPI 3 - Faturamento por Produto

KPI 4 - Quantidade Vendida por Produto

KPI 5 - Ranking de Clientes

KPI 6 - Faturamento por Mês

Parte 5 - Transformando Dados em Informação

Criar a tabela dinâmica não é o objetivo final.

O analista deve interpretar os resultados e responder questões como:

  • Qual produto gera mais faturamento?
  • Qual cidade apresenta melhor desempenho?
  • Quem são os principais clientes?
  • Existem meses com crescimento ou queda nas vendas?
  • Quais oportunidades ou problemas podem ser identificados?

Conclusão

Dados sozinhos não geram valor.

O BI transforma dados em informação para auxiliar a tomada de decisão.

A Tabela Dinâmica mostra o que aconteceu.
Os KPIs mostram o que é importante.
O analista descobre por que aconteceu e o que fazer a seguir.
