KNIME + Power BI

Tutorial Completo - Análise de Dados de uma Oficina Mecânica

Objetivo da Aula

Demonstrar um fluxo completo de Business Intelligence utilizando:
  • KNIME para ETL e tratamento de dados
  • Power BI para visualização
  • CSV de uma oficina mecânica como fonte de dados

Fluxo da Solução

CSV Oficina ↓ KNIME ↓ Tratamento dos Dados ↓ Indicadores ↓ CSV Analítico ↓ Power BI ↓ Dashboard Executivo
