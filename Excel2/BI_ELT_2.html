CASE BI - TECHMAX

A TechMax comercializa equipamentos de informática através de lojas físicas e e-commerce. A diretoria deseja entender melhor os resultados da empresa através de indicadores de desempenho (KPIs).

Objetivo

Importar dados de múltiplas fontes, realizar o processo de ELT utilizando Power Query e gerar informações através de Tabelas Dinâmicas.

Etapa 1 - Importação dos Dados

Importe os arquivos CSV utilizando:

Dados → Obter Dados → De Texto/CSV

Ao final, você deverá possuir quatro consultas no Power Query.

Etapa 2 - Limpeza dos Dados

Realize as correções necessárias:

  • Remover registros duplicados.
  • Corrigir cidades com e sem acentuação.
  • Corrigir categorias com grafias diferentes.
  • Padronizar nomes de clientes.
  • Tratar dados nulos ou vazios.
  • Verificar datas inválidas.

Etapa 3 - Mesclar Consultas

Vendas + Clientes

Relacionar pelo campo ID_Cliente.

Adicionar:

  • Nome do Cliente
  • Cidade
  • Estado
  • Segmento

Vendas + Produtos

Relacionar pelo campo ID_Produto.

Adicionar:

  • Produto
  • Categoria
  • Fornecedor
  • Custo

Etapa 4 - Criar Colunas Calculadas

Faturamento

Quantidade × Valor_Venda

Custo Total

Quantidade × Custo

Lucro

Faturamento − Custo Total

Etapa 5 - Carregamento

Página Inicial → Fechar e Carregar

Os dados tratados serão utilizados para criar os relatórios.

Quanto a empresa vendeu?
KPI 2 - Lucro Total

Desafio Final

Após concluir as análises, responda:

  1. Qual cidade apresenta maior faturamento?
  2. Qual produto gera maior lucro?
  3. Qual categoria se destaca?
  4. Qual canal de vendas é mais eficiente?
  5. A empresa atingiu as metas definidas?
  6. Quais recomendações você faria para a diretoria?

Reflexão Final

Business Intelligence não é apenas criar gráficos ou dashboards.

O verdadeiro valor está em transformar dados dispersos em informações úteis para apoiar decisões.

Antes da análise existe um trabalho fundamental de integração, limpeza e validação dos dados.
