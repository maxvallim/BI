AVALIAÇÃO - BUSINESS INTELLIGENCE

Ao longo da disciplina foram estudados conceitos relacionados à Business Intelligence, ETL, modelagem de dados, Power Query, KNIME, criação de indicadores e construção de dashboards gerenciais no Power BI.

Nesta avaliação, o aluno deverá demonstrar sua capacidade de planejar, desenvolver e apresentar uma solução completa de Business Intelligence baseada em um problema real ou cenário de sua escolha.

Objetivo

Desenvolver uma solução completa de Business Intelligence utilizando os conhecimentos adquiridos durante a disciplina.

O aluno deverá definir o tema, construir ou obter os dados, realizar o tratamento das informações, desenvolver indicadores, criar dashboards e apresentar conclusões gerenciais.

Etapa 1 - Escolha do Tema

O tema é livre.

O aluno poderá escolher qualquer área de interesse, desde que exista um objetivo de análise claramente definido.

Exemplos:
  • Loja de roupas
  • Supermercado
  • Academia
  • Recursos Humanos
  • Oficina mecânica
  • Hospital
  • Escola
  • E-commerce
  • Produção industrial
  • Turismo
  • Transporte
  • Futebol

Etapa 2 - Construção da Base de Dados

O aluno deverá construir sua própria base de dados.

Os dados podem ser:

  • Criados manualmente
  • Obtidos em bases públicas
  • Gerados por inteligência artificial
  • Importados de planilhas ou arquivos CSV

A base deverá conter no mínimo:

  • 3 tabelas relacionadas
  • 50 registros na tabela principal
  • 20 registros nas tabelas auxiliares

Etapa 3 - ETL e Tratamento dos Dados

Utilizando Power Query, KNIME ou ambos, realizar:

  • Importação dos dados
  • Correção de inconsistências
  • Tratamento de valores nulos
  • Padronização de informações
  • Remoção de duplicidades
  • Validação dos dados

Etapa 4 - Modelagem dos Dados

Construir um modelo de dados adequado para análise.

Apresentar:

  • Tabelas utilizadas
  • Chaves de relacionamento
  • Cardinalidade dos relacionamentos
  • Modelo relacional final

Etapa 5 - Indicadores

Criar pelo menos 5 indicadores (KPIs) relevantes para o tema escolhido.

Exemplos:
  • Faturamento
  • Lucro
  • Ticket Médio
  • Turnover
  • Taxa de Ocupação
  • Produtividade
  • Quantidade Vendida
  • Custos Operacionais
  • Desempenho Médio

Cada indicador deverá ser justificado pelo aluno.

Etapa 6 - Dashboard

Desenvolver no mínimo três páginas de análise.

Página 1 - Visão Executiva

  • Indicadores principais
  • Resumo do negócio
  • Painel gerencial

Página 2 - Análise Operacional

  • Detalhamento dos dados
  • Gráficos analíticos
  • Comparações relevantes

Página 3 - Análise Estratégica

  • Identificação de tendências
  • Oportunidades de melhoria
  • Suporte à tomada de decisão

Etapa 7 - Análise Gerencial

Elaborar uma análise respondendo:

  1. Qual problema ou oportunidade foi identificado?
  2. Quais indicadores foram mais relevantes?
  3. Quais conclusões podem ser obtidas a partir dos dados?
  4. Quais decisões poderiam ser tomadas?
  5. Quais melhorias poderiam ser implementadas?

Entregáveis

  • Arquivo PBIX
  • Base de dados utilizada
  • Modelo Relacional
  • Dashboard final
  • Relatório gerencial (1 a 2 páginas)

Reflexão Final

No mercado de trabalho, analistas de BI raramente recebem problemas completamente definidos ou bases de dados prontas para análise.

O diferencial de um profissional está na sua capacidade de compreender o negócio, selecionar os dados relevantes, criar indicadores adequados e transformar informações em conhecimento para apoiar decisões.

Mais importante do que construir gráficos é compreender a história que os dados contam.

Dados → Informação → Conhecimento → Decisão → Resultado
