CASE BI - TALENTOCORP RH

A TalentoCorp RH atua na gestão de recursos humanos para empresas de médio porte. A diretoria deseja utilizar Business Intelligence para acompanhar indicadores estratégicos relacionados aos colaboradores, desempenho, absenteísmo e turnover.

Objetivo

Importar dados de múltiplas fontes, realizar o processo de ELT utilizando Power Query e gerar informações gerenciais através de Tabelas Dinâmicas.

Etapa 1 - Importação dos Dados

Dados → Obter Dados → De Texto/CSV

Ao final, você deverá possuir cinco consultas no Power Query.

Etapa 2 - Limpeza dos Dados

  • Remover registros duplicados.
  • Padronizar nomes de departamentos.
  • Padronizar cargos.
  • Corrigir inconsistências de cidades.
  • Tratar dados nulos ou vazios.
  • Verificar datas inválidas.
  • Validar registros inconsistentes.

Etapa 3 - Mesclar Consultas

Colaboradores + Desempenho

Relacionar pelo campo ID_Colaborador.

Colaboradores + Faltas

Relacionar pelo campo ID_Colaborador.

Colaboradores + Desligamentos

Relacionar pelo campo ID_Colaborador.

Etapa 4 - Criar Colunas Calculadas

Tempo de Empresa = Data Atual − Data_Admissao
Custo Anual = Salario × 12
Classificação: Nota ≥ 8 = Alto | Nota entre 6 e 7,99 = Médio | Nota < 6 = Baixo

Desafio Final

  1. Qual departamento possui mais colaboradores?
  2. Qual cidade concentra a maior quantidade de funcionários?
  3. Qual a média salarial da empresa?
  4. O turnover está dentro da meta?
  5. Quais são os principais motivos de desligamento?
  6. Como está o desempenho médio dos colaboradores?
  7. Quais recomendações você faria para a diretoria?
